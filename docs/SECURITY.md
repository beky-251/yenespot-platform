# Security Guidelines

1. Never commit secrets.
2. Never expose the Supabase service-role key to clients.
3. Enable Row Level Security on protected tables.
4. Validate untrusted input on the server.
5. Enforce role permissions on the server and database.
6. Restrict business owners to their own business records.
7. Validate uploaded files.
8. Record sensitive administrative actions.
9. Verify payment events on the server.
10. Test authorization before launch.
