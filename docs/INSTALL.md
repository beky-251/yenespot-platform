# Installation Guide

## Requirements
- Node.js
- Corepack
- pnpm through Corepack
- Git
- Visual Studio Code

## Install Dependencies
corepack pnpm install

## Start Website
corepack pnpm --filter @yenespot/web dev

## Start Mobile
corepack pnpm --filter @yenespot/mobile dev

Review the root .env.example before configuring external services.
